# 常见问题

**大部分问题这里都有答案。** 找不到的，到 QQ 群 **1102137231** 问值班管理员。

## 连接问题

| 现象 | 做法 |
|------|------|
| 提示版本不兼容 | 换成支持范围内的客户端，见[选择客户端](选择客户端.md) |
| 提示不在白名单 | 先完成绑定，见[入服与绑定](入服与绑定.md) |
| 连接超时 | 核对地址与端口 `202.189.10.108:20577`；仍不行就在群里反馈 |
| 基岩版连不上 | 地址与端口分开填：地址 `202.189.10.108`，端口 `20577` |

## 游戏玩法

| 问题 | 回答 |
|------|------|
| 刚进服该干什么 | 照着[新手教程](../玩法/新手教程.md)走：看公告栏、按 `Shift + F` 开菜单、离开主城圈领地 |
| 指令记不住 | 按 `Shift + F` 打开服务器菜单，传送、个人信息、点歌都在里面；指令速查见[指令与菜单](../玩法/指令与菜单.md) |
| 怎么回家、怎么传送 | 用菜单里的「传送」，或参考[指令与菜单](../玩法/指令与菜单.md)；以游戏内提示为准 |
| 怎么点歌 | 安装 AllMusic 客户端模组，用菜单里的点歌台或 `/music` 指令 |
| 能用假人吗 | 能，用来维持机器加载；5 个及以上要报备，见[红石指南](../玩法/红石指南.md) |
| 刷怪塔要不要审批 | 不用审批，大型机器建议报备一次，见[红石指南](../玩法/红石指南.md) |
| 房子能盖多大 | 不限，超过 128×128 或跨公共区域要报备，见[建筑指南](../玩法/建筑指南.md) |
| 东西被偷、房子被拆 | 先截图录像留证，再联系值班管理员，处理原则是恢复原状加封禁 |
| 能 PVP 吗 | 双方自愿就可以；主城、新手村、出生点禁止 PVP |
| 地铁要钱吗 | 免费，见[地铁乘车管理条例](../清屿服务器地铁乘车管理条例.md) |
| 怎么赚游戏币 | 做任务、参加活动、向官方商店卖东西，见[玩法总览](../玩法/玩法总览.md) |
| 能装哪些模组 | 优化、小地图（无实体雷达）、合成表查询可以；X-Ray、飞行加速等禁止 |
| 有测试服吗 | 有，地址见[服务器信息](../../服务器信息.md)，适合先试机器 |
| 有 VIP 或付费特权吗 | 没有，全员同一身份「贡献者」，见[玩家身份与治理条例](../清屿服务器玩家身份与治理条例.md) |

## 办事指南

| 问题 | 做法 | 时限 / 依据 |
|------|------|------------|
| 举报违规 | 提交截图、录像、日志等证据 | 12 小时内启动调查（管理员条例第十一条） |
| 申诉 / 解封 | QQ 群联系值班管理员，或提交 GitHub Issue | 7 日内提出，72 小时内复核（管理员条例第十二条） |
| 交易纠纷 | 提交双方 ID、交易内容与证据 | 12 小时受理，72 小时裁决（玩家守则 10.2.2） |
| 账号找回 | 提供注册邮箱、历史登录信息、最早建筑坐标等 | 核对通过后找回（玩家守则 12.6.1） |
| 店铺与营业执照 | 按商店告示牌标价，联系管理员办理 | 玩家守则 7.2.2 |
| 漏洞报告 | 提交详细复现步骤 | 首例重大漏洞奖励 500–5000 游戏币（玩家守则 2.1.2） |
| 地铁故障 | 提交线路、坐标、问题描述与截图 | 24 小时响应，48 小时处理（地铁条例 4.1.3） |
