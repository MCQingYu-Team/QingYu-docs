# 入服与绑定

**清屿实行白名单制。** 第一次进服需要绑定 QQ 群，全程自动，一般一分钟内完成。

## 绑定步骤

| 步骤 | 做法 |
|------|------|
| 一 | 加入官方 QQ 群 **1102137231** |
| 二 | 用客户端连接服务器，屏幕上会出现"绑定 xxxx"的提示 |
| 三 | 把这串绑定码发到 QQ 群 |
| 四 | 机器人校验通过后自动加白名单，并把你的群昵称改成游戏 ID |
| 五 | 重新连接服务器，开始游戏 |

> **注意：** 绑定码是你的身份凭证，不要发给别人，也不要替别人绑定。

## 绑定失败怎么办

- 绑定码失效、重复绑定或提示校验失败时，联系值班管理员处理，不要反复尝试。
- 群昵称没有自动变成游戏 ID 时，手动改成游戏 ID 即可。

## 加白条件

需要同时满足三条：拥有有效的游戏账号、完成绑定码校验、没有未处理的历史封禁记录。

服务器实行一人五号。家庭共用设备需要额外账号的，要事先向管理员报备。详见[玩家守则](../清屿服务器玩家守则.md)第五章。

## 进服之后

- 先读一遍[玩家守则](../清屿服务器玩家守则.md)，至少看完第二章游戏行为规范。
- 不清楚某个行为会不会被罚，查[处罚细目表](../处罚细目表.md)。
- 遇到问题先看[常见问题](常见问题.md)。
