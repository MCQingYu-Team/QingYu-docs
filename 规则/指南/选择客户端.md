# 选择客户端

**进服之前，先选一个合适的客户端。** 清屿同时支持 Java 版与基岩版，两边用同一套规则、同一个世界。

## 支持的版本

| 客户端类型 | 支持的最旧版本 | 支持的最新版本 |
|-----------|---------------|---------------|
| Java 版 | 1.20 | 26.3 |
| 基岩版 | 26.0 | 26.45 |

服务器当前的游戏版本是 **26.2**，服务端为 Paper。使用 **26.2** 的 Java 版客户端连接，兼容性最好。

> **提示：** 版本不在上表范围内会连接失败。请使用正式版客户端，测试版（快照、Beta、Preview）不保证能进。

## 连接地址

| 客户端 | 地址 |
|-------|------|
| Java 版 | `202.189.10.108:20577` |
| 基岩版 | `202.189.10.108`，端口 `20577` |

完整的服务器信息（测试服、网页地图、种子）见[服务器信息](../../服务器信息.md)。

## 基岩版玩家

- 基岩版通过 Geyser 接入，未启用 Floodgate，ID 没有前缀。
- Java 版与基岩版同 ID 账号的数据互通。
- 反作弊对基岩版豁免自动检测，但规则约束完全一样，详见[玩家守则](../清屿服务器玩家守则.md) 4.3。

## 可以装哪些模组

允许装不改变游戏机制、不提供额外信息的辅助模组，例如性能优化、小地图（不含实体雷达）、合成表查询。商店区域卡顿时，推荐装 ImmediatelyFast 提升帧率。

X-Ray、实体雷达、飞行加速、自动战斗等提供不公平优势的模组一律禁止。完整清单见[玩家守则](../清屿服务器玩家守则.md) 5.3。
