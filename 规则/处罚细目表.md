## 使用方式

1. **先定类别。** 依据违规行为的性质确定所属类别，跨类别的按最重的一类处理。
2. **再查情节。** 在对应类别文件中检索具体行为。表中未列明但性质相近的，管理员可参照最相近的条目处理，并在处罚记录中写明参照的编号。
3. **最后叠加。** 处罚结果需经《[管理员条例](清屿服务器管理员条例.md)》第十三条累计加重规则调整后执行。

## 处罚幅度说明

| 表述 | 含义 |
|------|------|
| 禁言 | 仅限制游戏内聊天与社群发言，不影响正常游戏 |
| 封禁 N 日 | 禁止登录服务器 N 个自然日，期满自动解封 |
| 永久封禁 | 无期限封禁，仅可通过申诉程序申请解封 |
| 恢复 / 归还 / 返还 | 违规者有义务将受影响方恢复至违规前状态 |
| 回收 | 由管理员没收违规所得物品、货币或权限 |

处罚幅度如需超出本表上限或低于下限，须由两名及以上管理员共同确认，并在公示中说明理由。
