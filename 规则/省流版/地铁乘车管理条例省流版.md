# 地铁乘车管理条例省流版

> 一页速查 ｜ 对应《[清屿服务器地铁乘车管理条例](../清屿服务器地铁乘车管理条例.md)》v2.0.0 ｜ 详细条款以完整版为准

## 一句话

**免费乘坐、不许破坏、不许占位、故障报修不要自己动手。**

## 禁止清单

- 拆轨道、站台、闸机、信号、照明、导向标识
- 往轨道上放方块、矿车、实体，向隧道灌岩浆或水
- 引燃爆炸物、破坏在建工区围挡
- 在车站和隧道里长期放私人物品、圈地、堆实体
- 堵车门、跳站台边缘、翻闸机、故意滞留影响通行
- 收取"地铁票""月票"费用（地铁完全免费）

## 乘车四步

1. 看导向标识，**先下后上**
2. 在安全线内候车，不跨越、不抛物
3. 车厢内不堵门、不占位、不放方块
4. 出站后随手让行——倡导不强制，但大家都舒服

## 出了问题

- 故障（停运、断轨、信号失效）：**不要自己修**，报给线路管理员
- 反馈渠道报修需带：线路名、站点或坐标、问题描述、截图
- 响应与处理时限：**24 小时响应、48 小时处理**；严重安全隐患立即处理

## 特殊时段

- 活动或高峰期可临时限流、单向通行、加开区间车，请服从引导
- 临时停运：非紧急提前公告；紧急停运 24 小时内说明原因与恢复时间
- 在建工区非施工人员禁入，施工期间必须保留至少一条通行路径

## 违规怎么罚

地铁违规按本条例定性 → 按[处罚细目表](../处罚细目表.md)定幅度 → 按《[管理员条例](../清屿服务器管理员条例.md)》第十一条流程执行、第十三条叠加加重。

典型条目：`P-005`（破坏地铁设施）、`P-024`（破坏轨道）。
