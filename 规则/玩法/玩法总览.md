# 玩法总览

**清屿是一个生存服，五个关键词：生存、红石、建筑、地铁、赛事。** 没有等级、没有付费特权，所有玩家都是同一个身份「贡献者」。

## 生存

原版生存为主，服务端是 Paper，游戏版本 **26.2**。Java 版与基岩版玩家在同一个世界，同 ID 数据互通。

- 资源够用就好，不要为刷资源大面积破坏地形，资源世界不在此限，见[玩家守则](../清屿服务器玩家守则.md) 6.4.1。
- 想先试试机器或建筑？测试服地址见[服务器信息](../../服务器信息.md)。

## 红石

这是一个生电服，欢迎各种刷怪塔、农场、物流。

- 可以用假人维持区块加载，5 个及以上需要报备。
- 大型机器建议开工前找管理员做一次报备，拿到降低卡顿的建议。

具体要求见[红石指南](红石指南.md)。

## 建筑

圈好领地就能自由建造。大型工程（超过 128×128、跨公共区域、涉及地铁）需要提前报备。

具体要求见[建筑指南](建筑指南.md)。

## 地铁

服务器有玩家共建的地铁网络，**免费乘坐**。在[网页地图](http://202.189.10.108:20851)上可以看到站点分布。

乘车礼仪、故障反馈和施工报备见[地铁乘车管理条例](../清屿服务器地铁乘车管理条例.md)。

## 赛事与活动

服务器定期举办 PVP 赛事和各种活动，比赛输赢不影响你在生存区的发展。报名资格、比赛规则、奖励发放写在[玩家守则](../清屿服务器玩家守则.md)第九章。

## 经济

服务器货币叫游戏币，通过任务、活动、向官方商店出售物品获得。

| 想做的事 | 怎么做 |
|---------|-------|
| 买东西 | 去官方商店，价格以游戏内标价牌为准 |
| 开店 | 在商业区申请店铺，联系管理员办营业执照 |
| 和玩家交易 | 双方自行约定，建议在公共频道确认交易内容，方便日后举证 |
| 被骗了 | 提交双方 ID 和证据申请仲裁，12 小时受理、72 小时裁决 |

详见[玩家守则](../清屿服务器玩家守则.md)第七章。

## 社区与治理

- 没有 VIP、没有等级，全员都是「贡献者」，见[玩家身份与治理条例](../清屿服务器玩家身份与治理条例.md)。
- 重大事项由玩家表决，规则修订公示 7 天，见[七日阳光流程](../清屿服务器七日阳光流程.md)。
- 想直播、录视频也可以，注意直播规范和署名，见[玩家守则](../清屿服务器玩家守则.md)第十一章。
