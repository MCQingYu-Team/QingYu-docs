# 指令与菜单

**大部分功能按 `ESC` 打开服务器菜单就能找到，不用背指令。** 下面列出常用指令，方便习惯打字的玩家。

> **以游戏内为准：** 服务器插件会随版本更新，个别指令可能调整或停用。打出指令没反应时，改用菜单，或在群里问管理员。

## 服务器菜单

按 `ESC` 打开暂停界面，点服务器菜单入口进入。

| 菜单 | 能做什么 |
|------|---------|
| 功能 | 服务器常用功能入口 |
| 传送 | 去主城、常用地点，或向其他玩家发起传送 |
| 个人信息 | 查看自己的称号、公会、客户端版本等 |
| 音乐 | 打开点歌台，搜歌点歌 |

## 点歌

服务器支持全服点歌，需要安装 AllMusic 客户端模组才能听到声音。

| 指令 | 作用 |
|------|------|
| `/music <歌曲 ID>` | 点一首歌，平台会按 ID 自动识别 |
| `/music search <关键词>` | 搜索网易云音乐 |
| `/music searchapi qqmusic <关键词>` | 搜索 QQ 音乐 |
| `/music vote` | 投票切歌 |
| `/music stop` | 自己不听了，关掉音乐 |

点歌台菜单里有同样的功能，用鼠标点更方便。

点歌前请先看《[点歌台管理条例](../清屿服务器点歌台管理条例.md)》，禁点内容不得点播。

## 传送与家

推荐直接用菜单里的「传送」。服务器常见的传送指令写法如下，可用范围以游戏内提示为准：

| 指令 | 作用 |
|------|------|
| `/spawn` | 回到主城出生点 |
| `/tpa <玩家>` | 请求传送到某位玩家身边 |
| `/tpaccept` / `/tpdeny` | 接受 / 拒绝别人的传送请求 |
| `/sethome [名字]` | 把当前位置设为家 |
| `/home [名字]` | 回家 |
| `/back` | 回到上一个位置或死亡点 |

> **注意：** 不要用传送请求骚扰别人，对方拒绝后不要反复发。

## 原版常用指令

| 指令 | 作用 |
|------|------|
| `/msg <玩家> <内容>` | 私聊 |
| `/list` | 查看在线玩家 |
| `/seed` | 查看世界种子（也可以在[服务器信息](../../服务器信息.md)里找到） |
| `/help` | 查看你能用的全部指令 |

## 用指令的规矩

- 不要用指令或脚本高频刷屏、刷指令输出，会按作弊类处罚（[处罚细目](../处罚细目/03-作弊类.md) C-019）。
- 发现指令能刷物品、刷钱，是漏洞，请上报，不要利用。
