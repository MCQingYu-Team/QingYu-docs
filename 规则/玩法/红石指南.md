# 红石指南

**清屿欢迎红石和生电玩法，只要不拖垮大家的服务器。** 这一页把守则里和机器有关的规定整理成了一张清单。

## 开工前的检查清单

| 检查项 | 要求 | 依据 |
|-------|------|------|
| 位置 | 建在自己领地里，不占公共区域和交通要道 | [玩家守则](../清屿服务器玩家守则.md) 6.1 |
| 规模 | 大型刷怪塔、全自动农场、公共物流系统建议先报备 | [玩家守则](../清屿服务器玩家守则.md) 2.3.2 |
| 实体 | 不能持续大量生成掉落物、怪物、矿车、船 | [玩家守则](../清屿服务器玩家守则.md) 2.3.1 |
| 区块 | 不能造成大范围区块强加载 | [玩家守则](../清屿服务器玩家守则.md) 2.3.1 |
| 假人 | 5 个及以上要在群里报备 ID 与用途 | [玩家守则](../清屿服务器玩家守则.md) 4.1.3 |

> **报备不是审批。** 管理员只做一次风险评估，给出降低卡顿的建议。报备记录以后出现性能争议时也能保护你。

## 假人怎么用

**可以：** 用假人维持刷怪塔加载、保持区块活跃。

**不可以：**

- 用假人挂机刷游戏币、经验、商店奖励或赛事积分
- 超量部署假人绕过在线人数或资源限制
- 用假人占公共位置、挡路、占领地
- 服务器卡的时候还开着大量假人、拒不调整

## 让机器更省性能

下面是减轻服务器负担的常见做法，管理员报备时也会这样建议：

- **掉落物及时收集。** 用漏斗、收集矿车把产物送进箱子，别让物品堆在地上。
- **怪物及时处理。** 刷怪塔的击杀区不要囤积大量存活的怪物。
- **加时钟开关。** 不用的时候能关掉，别让机器一直空转。
- **控制加载范围。** 只加载机器真正需要的区块。
- **分批测试。** 先在[测试服](../../服务器信息.md)跑一遍，确认没问题再搬到主服。

值班管理员发现性能异常时，可以先暂停相关装置，再请你限期整改。

## 不要碰的红线

- 未经许可改造别人的红石装置
- 用活塞、水流、岩浆干扰别人的机器
- 利用复制类漏洞刷物品（发现漏洞请上报，首例重大漏洞有 500–5000 游戏币奖励）

对应处罚见[处罚细目表](../处罚细目表.md)的破坏类与作弊类。
