# 新手教程

**第一次来清屿？照着这一页走，五分钟就能开始玩。** 规则原文很长，这里只挑新人最需要知道的部分。

## 三步进服

| 步骤 | 做法 | 详细说明 |
|------|------|---------|
| 一 | 准备 Java 版 1.20–26.3 或基岩版 26.0–26.45 客户端 | [选择客户端](../指南/选择客户端.md) |
| 二 | 加 QQ 群 **1102137231**，连接 `202.189.10.108:20577` | [服务器信息](../../服务器信息.md) |
| 三 | 把屏幕上的"绑定 xxxx"发到群里，重新连接 | [入服与绑定](../指南/入服与绑定.md) |

> **小技巧：** 基岩版的地址和端口要分开填：地址 `202.189.10.108`，端口 `20577`。

## 第一天做什么

1. **先看公告栏。** 主城公告栏会贴出最新活动和规则变动。
2. **打开服务器菜单。** 按 `ESC` 就能看到服务器菜单，传送、个人信息、点歌都在里面，比记指令省事。
3. **离开主城找地方安家。** 主城、新手村、出生点是公共区域，不能在里面私自建房。
4. **圈一块领地。** 用领地插件把家圈起来，别人就动不了你的东西。领地大小跟实际建筑匹配就好，不要圈太大。
5. **打开网页地图看看。** [网页地图](http://202.189.10.108:20851)能看到整个世界，方便找空地、找地铁站、找邻居。

## 新人最容易踩的坑

| 不要做 | 为什么 | 依据 |
|-------|-------|------|
| 拿别人箱子里的东西、拆别人的房子 | 没有许可就算偷窃和破坏，会封禁并要求恢复原状 | [玩家守则](../清屿服务器玩家守则.md) 2.2.1 |
| 装 X-Ray、小地图实体雷达、飞行加速 | 属于作弊模组，一律禁止 | [玩家守则](../清屿服务器玩家守则.md) 5.3.2 |
| 在主城、新手村打人 | 安全区禁止 PVP，野外也要双方都同意 | [玩家守则](../清屿服务器玩家守则.md) 4.2 |
| 一次性刷出成堆掉落物、矿车、船 | 会拖垮全服性能 | [玩家守则](../清屿服务器玩家守则.md) 2.3.1 |
| 用现实里的钱买卖游戏币、物品 | 禁止现实货币交易 | [玩家守则](../清屿服务器玩家守则.md) 7.4.1 |
| 把绑定码发给别人 | 绑定码就是你的身份凭证 | [玩家守则](../清屿服务器玩家守则.md) 5.1.1 |

不确定某件事会不会被罚，先查[处罚细目表](../处罚细目表.md)，或者在群里问一句。

## 可以放心做的事

- **装优化模组。** 性能优化、小地图（不带实体雷达）、合成表查询都可以。商店卡顿推荐装 ImmediatelyFast。
- **用假人挂机器。** 用假人维持刷怪塔、农场的加载是允许的，5 个及以上要在群里报备。
- **开店做生意。** 在商业区开店，办好营业执照就能营业。
- **免费坐地铁。** 服务器地铁免费乘坐，[地铁乘车管理条例](../清屿服务器地铁乘车管理条例.md)写了乘车礼仪。
- **参与改规则。** 规则改动都要公示 7 天，你可以提意见、参与表决，见[七日阳光流程](../清屿服务器七日阳光流程.md)。
