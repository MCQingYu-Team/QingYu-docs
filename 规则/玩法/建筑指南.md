# 建筑指南

**圈好领地，就可以放开盖。** 只要不影响邻居、不占公共区域，清屿对建筑风格没有限制。

## 盖房四步

| 步骤 | 做法 |
|------|------|
| 一 | 在[网页地图](http://202.189.10.108:20851)上找一块没人用的空地 |
| 二 | 用领地插件圈出领地，范围和实际建筑差不多大 |
| 三 | 需要朋友一起建的，由领地所有者把对方加进领地白名单 |
| 四 | 开始建造，大型工程先报备 |

## 领地规则

- 只有领地所有者能给别人加权限，不要改动别人领地的权限。
- 不要恶意圈大片地，不要圈公共资源点和交通要道，不要用领地把别人的建筑围起来。
- 连续 60 天没登录、领地里也没有建筑的，管理员可以回收并公示。

依据：[玩家守则](../清屿服务器玩家守则.md) 6.1。

## 和邻居相处

- 不要挡别人的采光、通道和景观视线。
- 在别人看得见的地方要盖大型建筑，先和对方打个招呼。
- 建筑外观不能有违法违规、色情、暴力、恐怖、歧视内容，也不能用未经授权的他人肖像。

依据：[玩家守则](../清屿服务器玩家守则.md) 6.2。

## 什么时候要报备

满足任意一条，开工前就要找管理员报备：

| 情况 | 例子 |
|------|------|
| 占地超过 128×128 方块 | 城镇、大型建筑群 |
| 跨越公共区域、道路、水域 | 跨海大桥、穿过主路的建筑 |
| 涉及公共地铁、公共物流 | 新建地铁站、改线 |
| 会持续加载大量实体或区块 | 大型展示馆、实体雕塑 |

不报备又影响到别人的，管理员会要求限期整改，整改不到位拆除的损失由建造者承担。依据：[玩家守则](../清屿服务器玩家守则.md) 4.4。

## 公共区域

主城、新手村、公共道路、桥梁、地铁、公共农场、公共照明都是大家的。不要破坏、私自改建或占用。看到公共设施坏了，欢迎告诉管理员。

修建或改动地铁设施，还要遵守[地铁乘车管理条例](../清屿服务器地铁乘车管理条例.md)第四章的施工规定。

## 被拆家了怎么办

1. 不要自己去报复，先截图、录像留证据。
2. 在 QQ 群联系值班管理员，或通过举报通道提交证据，12 小时内启动调查。
3. 处理原则是"恢复原状 + 封禁"，确实恢复不了的按市场价赔偿。
