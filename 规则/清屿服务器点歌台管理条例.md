# 清屿服务器点歌台管理条例

> **版本：** v1.0.0 ｜ **更新日期：** 2026.10.24 ｜ **生效日期：** 2026.10.31 ｜ **面向对象：** 全体玩家

《清屿服务器点歌台管理条例》（以下简称"本条例"）是清屿服务器全服点歌功能的专项规范。服务器点歌为全服共享播放，一首歌会被所有在线且安装了 AllMusic 客户端模组的玩家听到。本条例与《[清屿服务器玩家守则](清屿服务器玩家守则.md)》并行适用；玩家守则中关于交流、刷屏、低俗内容的规定同样约束点歌行为。

::: danger 总则
不得点播任何属于禁点内容的歌曲或视频，严禁任何恶意行为。
:::

## 第一章　点歌指令

### 1.1 准备

听歌和点歌都需要安装 AllMusic 客户端模组，未安装的玩家听不到声音。

### 1.2 点歌台菜单

按 `Shift + F` 打开服务器菜单，进入「音乐」即可打开点歌台，用鼠标完成搜索和点歌。

### 1.3 指令

| 指令 | 作用 |
|------|------|
| `/music <歌曲 ID>` | 点一首歌，平台会按 ID 自动识别 |
| `/music search <关键词>` | 搜索网易云音乐 |
| `/music searchapi [平台] <关键词>` | 搜索指定平台音乐 |
| `/music vote` | 发起或参与投票切歌 |
| `/music stop` | 自己不听了，关掉音乐 |

## 第二章　禁点内容

### 2.1 歌曲类禁点内容

1. 刺耳、噪音等令人难以忍受的歌曲；
2. 无内容、无意义的空白歌曲；
3. 恐怖、核爆歌曲。

### 2.2 视频类禁点内容

1. 与音乐无关的视频，如恐怖视频、擦边视频、游戏解说、电台、新闻时政、宣传片、混剪等；
2. 背景音乐过于嘈杂，或有过多人声干扰的视频（音乐 MV 除外）。

### 2.3 其他

歌曲或视频的内容、歌词、封面、标题违反《[玩家守则](清屿服务器玩家守则.md)》（如色情、血腥暴力、政治敏感、辱骂他人）的，同样属于禁点内容。

## 第三章　规则说明

### 3.1 恶意行为

以下行为属于恶意点歌，严禁实施：

1. 明知是禁点内容仍然点播，或换平台、换 ID 重复点播已被切掉的禁点内容；
2. 短时间内大量连续点歌，占满播放队列；
3. 借歌名、视频标题对他人进行辱骂、骚扰或宣传其他服务器；
4. 故意点播用于干扰他人、引发争吵的内容。

### 3.2 拿不准时

不确定一首歌或一个视频是否属于禁点内容的，先在游戏内或官方社群询问管理员，再决定是否点播。

### 3.3 切歌

正在播放的内容属于禁点内容的，玩家可使用 `/music vote` 投票切歌，也可联系管理员处理。管理员有权直接切掉禁点内容，无需经过投票。

## 第四章　违规处理

### 4.1 处理依据

点歌相关的违规，依据本条例定性，依据[处罚细目表](处罚细目表.md)确定幅度，依据《[管理员条例](清屿服务器管理员条例.md)》第十一条流程执行，并按第十三条叠加累计加重。

### 4.2 申诉

对点歌相关处罚有异议的，按《[玩家守则](清屿服务器玩家守则.md)》3.2 与《[管理员条例](清屿服务器管理员条例.md)》第十二条申请复核。

### 4.3 修订

本条例的修订遵循"七日阳光流程"，修订版须公示 7 日后方可生效（完整定义见《[清屿服务器七日阳光流程](清屿服务器七日阳光流程.md)》）。
