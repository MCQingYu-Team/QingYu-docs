## 常见问题速查

| 问题 | 做法 | 时限 / 依据 |
|------|------|------------|
| 入服白名单 | 进服获取绑定码 → 发送至官方 QQ 群自动绑定 | 即时生效（见玩家守则 5.1.1） |
| 举报违规 | 提交截图、录像、日志等证据 | 12 小时内启动调查（见管理员条例 第十一条） |
| 申诉 / 解封 | QQ 群联系值班管理员，或提交 GitHub Issue | 7 日内提出，72 小时内复核（见管理员条例 第十二条） |
| 交易纠纷 / 仲裁 | 提交双方 ID、交易内容与证据 | 12 小时受理，72 小时裁决（见玩家守则 10.2.2） |

其余高频问题（账号找回、店铺与营业执照、漏洞奖励、地铁故障）见[常见问题](规则/指南/常见问题.md)。

## 规则修订：七日阳光流程

一句话：**规则不能"偷偷"改**。任何修订草案都必须先在官方渠道公示满 7 日、充分收集意见，才能生效；涉及服务器安全或数据安全的紧急修复可以先修后公示，但须在 24 小时内补发公示、48 小时内提请追认。

完整定义（三条原则、四步流程、各角色职责、紧急修订的三条约束）见 [清屿服务器七日阳光流程.md](规则/清屿服务器七日阳光流程.md)。改了什么，见[最近更新](规则/最近更新.md)。
