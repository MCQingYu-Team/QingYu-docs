## 常见问题速查

| 问题 | 做法 | 时限 / 依据 |
|------|------|------------|
| 入服白名单 | 进服获取绑定码 → 发送至官方 QQ 群自动绑定 | 即时生效（见玩家守则 5.1.1） |
| 举报违规 | 通过举报通道提交证据（截图、录像、日志等） | 12 小时内启动调查（见管理员条例 第十一条） |
| 申诉 / 解封 | 官网或 QQ 群联系值班管理员、提交 Issue 申诉 | 7 日内提出，72 小时内复核（见管理员条例 第十二条） |
| 交易纠纷 / 仲裁 | 提交双方 ID、交易内容与证据 | 12 小时受理，72 小时裁决（见玩家守则 10.2.2） |
| 账号找回 | 提供注册邮箱、历史登录信息、最早建筑坐标等证据 | 核对通过后找回（见玩家守则 12.6.1） |
| 店铺购买 / 出租 / 营业执照 | 按商店告示牌标价，联系管理员办理 | 见玩家守则 7.2.2 |
| 漏洞报告 | 提交详细复现步骤 | 首例重大漏洞奖励 500–5000 游戏币（见玩家守则 2.1.2） |
| 地铁问题反馈 | 提交线路、坐标、问题描述与截图 | 24 小时响应，48 小时处理（见地铁条例 4.1.3） |

## 规则修订：七日阳光流程

**七日阳光流程 = 草案公开 + 公示七日 + 通过后生效 + 全程留痕。**

一句话：**规则不能"偷偷"改**。任何修订草案都必须先在官方渠道公示满 7 日、充分收集意见，才能生效；涉及服务器安全或数据安全的紧急修复可以先修后公示，但须在 24 小时内补发公示并登记。

完整定义（三条原则、四步流程、各角色职责、紧急修订的三条约束）见 [清屿服务器七日阳光流程.md](规则/清屿服务器七日阳光流程.md)。
